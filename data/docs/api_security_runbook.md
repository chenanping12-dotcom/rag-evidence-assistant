# API 安全与密钥管理手册

## 密钥生命周期
平台密钥采用创建、轮换、吊销三阶段管理。生产密钥默认 90 天轮换，轮换时先创建新密钥并灰度验证，再撤销旧密钥，避免正在运行的请求失败。日志仅记录 key_id 的哈希前缀，不记录完整密钥。

## 访问控制
服务账号按最小权限分配 scope。读取知识库只允许 read:documents，写入索引需要 write:index，管理租户需要 admin:tenant。异常的 scope 变更必须触发审批和审计事件。

## 安全告警
连续 5 分钟出现 401 或 403 的请求比例超过 2% 时触发告警；同一 key_id 在异常地域并发访问时进入限流队列。
