# AI 网关故障处理手册

## Provider 故障

当主模型供应商返回 429、5xx 或连接超时时，网关只对可重试的传输类错误执行有限次数重试，并切换到备用 Provider。鉴权失败和参数错误不应盲目重试，否则会放大故障和成本。

## 流式响应

SSE 响应需要逐事件转发，并在客户端断开时取消上游请求。网关应记录 request_id、provider、model、首 token 延迟、总耗时和 token usage。最后一个事件缺少 usage 时，计量模块应使用可解释的降级策略并标记估算状态。

## 预算与审计

每个虚拟 Key 绑定调用方、模型白名单和预算。超过预算后，系统可以切换低成本模型或返回可重试错误。审计日志至少包含时间、调用方、路由结果、状态码和错误类别，不应记录完整用户密钥。

## 评测要求

故障转移测试至少覆盖主 Provider 超时、429、5xx、备用 Provider 不可用和客户端取消。每类用例记录成功率、切换耗时、重试次数和是否出现重复副作用。
